# WPY 部署入口

现有部署使用 Python 标准库、SQLite、systemd 和 Caddy。
开发检出与正式运行目录分开；修改源码、合并 PR 或关闭编辑器均不触发发布。

日常开发见[维护约定](../docs/MAINTENANCE.md)。
预览、候选构建、发布、健康检查、代码回滚和数据备份见[发布流程](../docs/RELEASES.md)。

## 已有部署升级

先读取实际 systemd 配置、环境文件位置、监听端口和 Caddy 中本项目路由。
不要用仓库 Caddy 示例覆盖共享网关，不用源码同步命令覆盖正式目录。
保留账号、私有页面、图片、数据库和通知/AI 状态，使用固定版本独立发行目录。
本机路径和部署版本记录在工作区记忆，不把真实配置或数据复制到仓库。

本目录 unit/env/Caddy 是初装参考。部分旧模板（例如统计刷新 --all、源码工作目录）
与现行部署不同，不能直接覆盖已有服务。站点发布使用专用 drop-in 固定代码和解释器，
保留现有环境、访问边界和任务参数。通知和 AI 按各自文档独立部署。

## 新机器初装

按实际需要建立服务用户、发行目录、私有配置和可写数据目录，用合成数据验证。
审查模板路径、参数、域名和访问边界后安装所需 unit；Web 监听本机，网关只添加本项目路由。
密钥不提交，文件权限按服务需要最小化。不默认复制正式库、授权定时抓取、发信或启动 AI 互动。
