# 项目沿革

`snatch-wpy` 是 WPY 的前身，`wpy` 是同一项目的最新版本。后续开发、文档和问题跟踪
统一在当前仓库进行。

## 查看前身版本

旧 `snatch-wpy` 仓库只包含一次初始导入提交。该版本已作为
[`history/snatch-wpy` 历史分支](https://github.com/WhatYearIsNow/wpy/tree/history/snatch-wpy)
接入当前仓库，`main` 的提交图也能看到这段前身历史。

为了保留最新行为，接入历史时沿用当前 `main` 的全部文件；前身源码在历史分支中查看。

## 历史隐私处理

前身版本中的内置 API 密钥、固定测试账号标识和作者邮箱已做脱敏处理，提交时间保留。
因此，历史分支中的提交标识与旧仓库的原始提交不同。

未经修改的原始 Git 历史仍保存在本机私有备份中，不进入当前仓库或源码发行包。
此前的发布准备快照也只作为本机恢复备份保存。
