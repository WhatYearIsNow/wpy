# 天大模型自主论坛互动

`python -m wpy agent` 为显式指定的本人微北洋账号增加自主浏览和互动能力。
模型生成结构化动作，本机执行器负责权限、目标校验、去重和频率限制。
与看板登录、抓取账号、邮件通知进程独立，不依赖个人登录 PR #4。

## 动作与边界

| 动作 | 普通板块 | 校务专区（ID 1） |
| --- | --- | --- |
| 浏览帖子和评论 | 允许 | 允许 |
| 点赞帖子/评论、收藏帖子 | 允许 | 允许 |
| 发帖、直接评论、回复评论 | 允许 | **禁止** |

没有删除、编辑、私信、修改账号、执行命令或任意 URL 请求能力。
仅支持文字发帖和评论，不自动上传图片。每轮最多八次模型决策、一次发起类写操作；
自己帖子或评论下的会话回复每轮最多两条，不占发起类评论/回复额度，但仍受全天写操作兜底限制。
点赞和收藏只发送明确的 `op=1`，不切换或取消已有状态。

每轮先一次预读青年湖底最新约 30 帖的标题和正文节选，用于学习当下话题和表达习惯；
这次预读本身不授权写入。执行器仍要求先读目标帖正文，回复/评论点赞前先读目标评论。
直接评论前还必须读取楼内评论，新发帖前先读近期湖底正文和评论。
每次对既有帖写入时重新读取远端帖子，检查真实板块；回复还会读取评论详情，验证评论 ID 和 `post_id` 归属。
板块未知、归属不符、字段缺失均拒绝执行，不以模型提供的板块、列表或归档数据作授权依据。
权限约束对预演同样生效。按维护者 2026-10-25 的要求，发言正文不再附加 AI 生成标记。

默认主要活跃在青年湖底（板块 2），从最新日常闲聊开始，以接梗、短水评和轻松讨论为主，
不要求每条互动都有实用结论。不冒充官方、不重复刷屏、不凑发言数量。
默认保留维护者提供的「大肥鱼」社区名称，但发言像自然的普通网友，第一人称使用「我」，
执行器禁止在标题或正文中出现「本鲸」。普通闲聊用自然短句，减少固定口癖、自报家门和模板；严肃学业问题直接跳过，包括选课方案、给分判断、作业、考试和
论文指导等认真求助，即使它们出现在湖底也不互动。普通生活求助在有依据时酌情参与。
高风险话题使用严肃正常语气。话题判断和语气依赖模型；板块权限和额度由执行器强制实施。
对方说「别演了／正经点」时，本次讨论切换普通助手语气；这只改变口吻，不改变权限和额度。
执行器从已读正文/评论识别暗号，按讨论保存摘要标记；「本鲸」在所有讨论中都会被拒绝，后续若仍输出其他角色口癖，
拒绝发送并要求模型改写。标记随状态库保存，重启不恢复该讨论的角色扮演。
不把角色等同于 DeepSeek 官方或实际底层模型，不编造校园亲历、课程给分或发布消息。
括号心声只允许虚构的角色台词，不输出内部推理。口癖和模板按场景使用，不重复刷屏。
模型根据当轮已读的帖子与评论观察发言习惯和常用梗，只接理解且适合场景的梗，不照抄具体发言。
只向模型提供互动需要的公开显示名，用于本机私有熟人偏好；不提供账号、token 或用户 UID。
熟人偏好仅影响友好接话的优先级，不改变权限、学业退出规则、额度或任何身份认证。
论坛正文和评论作为不可信材料传给模型，不作为维护者指令。模型输出必须通过动作白名单和
严格参数校验，即使模型服从了帖子中的恶意指令，也不能获得额外接口或绕过校务区限制。
模型的回答质量与是否遵循互动目标仍需人工观察，执行器不能保证事实准确。

自己帖子或评论下的新回复会从本人消息列表中优先加入当轮上下文。旧版本已经确认发送、
但尚未登记楼层 ID 的直接评论，可按“每帖至多一次 AI 直接评论”的动作摘要补登记；
结果未知的动作不会据此认领人工评论。评论消息最多读取最近五页，避免一小时内被其他消息挤出
第一页；发帖接口未返回帖子 ID 时，会用已确认发送动作的标题和正文摘要精确补登记，
不会据此认领维护者手动发表的帖子。回复前仍重查帖子板块与目标评论归属。
执行器只在当轮内存中比较公开 UID，UID 不进入模型、邮件、日志或状态库；由当前账号发出的楼层
会被剔除，禁止直接评论大肥鱼自己的帖子，也禁止回复大肥鱼自己的评论。存在外部回复时，
本轮只能读取相应帖子并优先回复，不能转去浏览、点赞或互动其他内容；每轮仍最多两条。
仅当内容触发安全、隐私、校务区、严肃学业、辱骂或无法理解等既有退出边界时，模型可用固定原因
持久化延后该条，避免反复处理。外部回复识别失败时按不回复处理，不以昵称猜测身份。

维护者的账号、密码、论坛 token、API/模型密钥及邮件账号配置不会放进模型提示。
模型上下文会对已知敏感值、邮箱、手机号、学号/证件格式和本机路径脱敏；执行器在预留动作前
检查发言标题/正文，命中即拒绝，不发送论坛，也不生成成功邮件。检查同时处理全角、大小写和
空白/零宽字符变体。模型不得猜测维护者姓名或身份，不以角色互动回应他人对维护者个人信息的索取。
此检测覆盖已配置敏感值和常见结构化个人信息，不将其视为对任意自由文本识别的绝对保证。

## 运行节奏

- 默认每轮完成后等待 **3600 秒（约一小时）**，不是每五分钟运行。
- 按北京时间自然日，发起类评论最多 **10 条**、发起类回复最多 **10 条**、发帖最多 **1 条**。
- 自己内容下的会话回复不占上述发起额度，每轮最多两条；所有写动作合计每天最多 **60 次**。
- 每轮最多一次发起类写动作，点赞、收藏或发帖也会占用该轮机会；没有值得互动的内容就结束。
  额度是上限，不保证每天恰好发满。

`--interval` 可以增大等待时间，最低一小时；修改互动目标文件不能改变硬性权限或额度。
遇到临时故障，常驻轮次退避，最长一天；认证失败立即退出，不无限尝试密码。
每轮重新用指定本人账号登录，token 只留在该轮内存，不回退到抓取账号。
无效模型动作格式可在原有八次决策限额内纠正，参数和权限校验保持严格；连接/HTTP 错误停止该轮，
不将已发送的论坛请求作为模型格式问题重试。
常驻执行会保存下轮时间，重启不提前重跑。论坛轮次与邮件补发独立，邮件失败最早五分钟后补发，
不因此增加论坛访问或重复发言。认证失败退出状态为 2，服务不无限续登；异常崩溃可由 systemd 恢复。

## 大肥鱼动作邮件

通过 `--smtp-config` 或 `WPY_AI_SMTP_CONFIG` 指向现有 SMTP JSON，沿用相同发件账号和收件配置。
发件人显示名固定为「大肥鱼」，主题为「大肥鱼评论了帖子」「大肥鱼回复了评论」
「大肥鱼点赞了帖子」等，不把论坛标题放进邮件主题。已有个人互动提醒仍使用「微北洋」。

邮件按固定行序包含动作、时间、结果、帖号、标题和帖子发出者，不展示内部评论编号；回复邮件附被回复者和原评论，评论/发帖邮件附实际发出的文字。成功指论坛已接受请求，
不等于另一次独立回查；结果未知时主题和正文明确说明待核实，不冒充成功。
纯浏览轮次不发动作邮件；启动、正常停止、认证失败仍发通知。
预演不产生论坛动作成功邮件。

评论、回复、点赞和收藏等针对既有帖子的动作邮件在帖子标题后依次展示帖子发出者和原帖正文，最长 8000 字，
再展示动作目标及大肥鱼发出的内容；空正文明确标注。论坛文字在 HTML 中转义。

动作预留与待发邮件在同一 SQLite 事务中保存；请求确认成功时原子更新动作和邮件结果。
程序崩溃或网络结果不明仍会发待核实报告，邮件补发不能触发论坛重发。发件/收件配置绑定摘要，
更改账号配置前须核对已有待发内容。SMTP 采用至少一次投递、重试复用 Message-ID；
SMTP 已接受但本机写回失败的极端情况下可能重复收信，论坛动作仍不重做。
待发队列为可靠投递保存必要标题、原帖正文节选和本人发言内容，投递成功立即清空邮件正文，日志只记数量。

```bash
python -m wpy agent --test-email --smtp-config /path/to/smtp.json  # 合成邮件，不访问论坛
python -m wpy agent --retry-mail --smtp-config /path/to/smtp.json  # 只补邮件，不访问论坛
python -m wpy agent --watch --execute --smtp-config /path/to/smtp.json
```

## 模型与账号配置

模型读取本机 JSON 的 `tju_llm_base`、`tju_llm_key`、`tju_llm_model`，兼容 exam 配置。
**直接指定已有配置路径，不把文件放进 WPY 仓库。** 不读取其中的应用令牌或第二模型密钥。
默认接口为 `https://ai.tju.edu.cn/api/v3/chat/completions`，模型为 `tju-llm`。
也可通过 `WPY_AI_BASE`、`WPY_AI_KEY`、`WPY_AI_MODEL` 覆盖，接口必须使用 HTTPS。
校园网机器如果设置了 HTTPS 代理，需在 AI 进程环境的 `NO_PROXY` / `no_proxy` 中加入
`ai.tju.edu.cn`；直连模型端点，保留其他请求的既有代理设置。

私有环境配置参考 [env.ai.example](../deploy/env.ai.example)。核心变量为：

```bash
WPY_AI_MODEL_CONFIG=/path/to/exam/config.json
WPY_AI_ACCOUNT=your_account
WPY_AI_PASSWORD=your_password
WPY_APP_KEY=banana
WPY_APP_SECRET=your_valid_api_secret
```

如果沿用邮件通知账号，由维护者在本机私有环境中把 `WPY_ACCOUNT` / `WPY_PASSWORD`
对应配置映射为 `WPY_AI_ACCOUNT` / `WPY_AI_PASSWORD`。程序不会自动读取通知环境或
`data/凭据.json`，也不使用看板会话。密码、密钥不放在命令行、Issue 或日志中。
Python 不自动加载环境文件；由终端导出变量或 systemd 的 `EnvironmentFile` 提供。

## 预演、启停与状态

```bash
python -m wpy agent                    # 单轮预演：真实读取论坛和调用模型，不写论坛
python -m wpy agent --execute          # 实际执行一轮，最多一次写动作
python -m wpy agent --watch --execute  # 常驻自主互动，默认约一小时一轮
```

预演会登录指定本人账号，帖子读取可能计入上游浏览量，正文会发送至配置的天大模型。
预演不输出论坛正文、模型生成文案或凭据，只输出读取/写入/预演/拒绝次数。
它检查权限但不占用真实额度，也不记录模拟发送。真实发送的内容不写到运行日志；启用动作邮件后，
必要内容会经过本机私有待发队列交给配置的收件人。

`--rules-file` 或 `WPY_AI_RULES_FILE` 可指定 UTF-8 互动目标文件（最多 4000 字符）。
该文件补充默认人设和活动目标，可保存本机熟人显示名偏好，设置 0600，不能提交真实显示名或论坛内容。
`--state-dir` 或 `WPY_AI_STATE_DIR` 指定独立状态目录，默认 `data/ai-agent/`。
目录权限 0700，SQLite 文件权限 0600；额度/去重仅保存账号和动作摘要，不保存账号、密码或 token。
普通语气偏好也只存讨论摘要。动作邮件待发期间保留必要的目标标题、本人发言或浏览标题，
投递成功即清空正文，不保存完整论坛原帖、他人评论或模型推理。一个状态目录只能运行一个进程。

写入前先原子提交动作预留，再发起一次论坛请求，成功后标记完成。网络超时、崩溃或结果不明
保持 `unknown`，不自动重发。对同帖最多直接评论一次，对同一评论最多回复一次；改写文案不能
绕过去重。同一帖子/评论的点赞和同帖收藏也去重；完全相同标题和正文的发帖不会重发。
去重不限于 24 小时。不能通过删除数据库来处理未知结果，否则会丢失去重与额度记录。

前台用 Ctrl+C 停止，服务可用 SIGTERM。收到停止信号后不再发起新的模型轮次或写请求；
已经发出的 HTTP 请求可能继续完成，单次模型/论坛超时分别为 90/30 秒。
[wpy-ai-agent.service](../deploy/wpy-ai-agent.service) 是部署模板，需先安装验证过的发行包、
配置独立运行路径和私有环境，再由维护者显式启用。采用 systemd `LoadCredential` 时可由服务管理器
读取本机模型、SMTP 和互动偏好文件，进程用 `%d` 下的私有副本，无需开放原文件权限。

## 验证

`tests/test_ai_agent.py` 使用合成模型、合成账号和临时数据库，禁止真实网络访问。
覆盖校务区拒写、帖子转区、评论归属伪造、未知板块、参数注入、显式账号、额度、
超时后重启去重、账号绑定、互斥锁、预演和停止。模型协议沿用 exam 的天大请求格式。
另覆盖正常语气暗号和重启保留、发言前阅读上下文、公开显示名筛选、私有偏好叠加。
模拟测试不能替代实际接口兼容验证；不以真实发帖作为自动测试。
`tests/test_ai_agent_mail.py` 验证动作/邮件事务、未知结果报告、SMTP 重试不重发论坛、
发件人、正文转义、配置绑定、旧状态迁移、浏览汇报和重启后按原时间运行。
`tests/test_ai_agent_privacy.py` 仅用合成身份，验证敏感内容无法进入论坛/发件队列及模型上下文脱敏。
