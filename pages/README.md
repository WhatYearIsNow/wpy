# 本地页面内容

这个目录保存经验手册等页面使用的本地内容。实际 `exp_*.json` 可能含论坛作者昵称、
帖子或评论正文，以及正文中的联系信息，因此不随公开源码、源码发行包或 wheel 分发。

仓库只提供三个空模板：

- `exp_add.example.json`
- `exp_refined.example.json`
- `exp_search.example.json`

模板是空 JSON 对象，不含作者、账号、帖子编号、正文或评论。它们用于说明本地文件的
位置和命名，不是经验手册的示例数据。只有使用本地手册功能时，才需要自行提供内容。
普通论坛看板可以在没有这些内容的情况下启动。

真实内容应放在不带 `.example` 的同名文件中，例如 `exp_refined.json`。
这些文件已由 Git 忽略，源码导出工具也会排除它们。不要将实际论坛内容改名为
`.example.json` 来提交；新增模板必须保持为空或只含人工编写的结构说明。

本地真实内容需要自行备份。清理 `build/` 中的手册页面前，先确认原始内容和生成方式
仍然可用；只有一份的页面不能当作可随时重建的缓存删除。
